# Security policy

Templinio has not made a stable release yet. Security fixes target the current default branch.

Do not open a public issue for a vulnerability. When the repository becomes public, use GitHub's
**Security → Report a vulnerability** flow. Until then, contact the maintainer privately through
[the GitHub profile](https://github.com/luantorv) without including secrets in a public message.

Include the affected commit, impact, a minimal reproduction, and any suggested mitigation. Please
allow time to validate and coordinate a fix before disclosure.

Templinio is informational software. Its lifecycle and advisory data must not be treated as a
security certification, and imported project files must never be executed.
