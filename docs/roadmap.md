# Public roadmap

Templinio is developed in independently useful, publishable increments. Dates are intentionally
not promised.

| Version | Milestone | Outcome |
| --- | --- | --- |
| v0.0 | Foundation | Reproducible build, data contract, source pilot, accessible visual base |
| v0.1 | Atlas | Searchable lifecycle catalog, technology pages, timeline, JSON/Markdown data |
| v0.2 | Constellation | Sourced conceptual relationships and graph exploration |
| v0.3 | Security | Normalized advisories, ranges, fixes, and explicit uncertainty |
| v0.4 | Workspace | Private, local analysis of npm manifests and lockfiles |
| v0.5 | Navigator | Explainable, constrained migration plan candidates |
| v0.6 | Roadmap | Reproducible maintenance stages and target dates |
| v0.7 | Interface | Versioned API, SDK, CLI, and explicit MCP tools |
| v0.8+ | Expansion | Additional ecosystems and formats based on demonstrated demand |

Atlas v0.1 is the current published milestone. It remains a valid product even if later milestones
are never built. Relationship graphs do not prove dependency or security impact, advisory matches
do not prove exploitability, and plans will not claim guaranteed compatibility without real
application tests.

The working roadmap contains detailed exit criteria and remains private until its language is
curated for public issue tracking.
